Grammatiska termer fungerar som precisa verktyg: när du behärskar begreppen blir det avsevärt enklare att förstå språkliga regler, slå upp i referensverk och bygga idiomatiska meningar.

Här hittar du en alfabetisk uppslagsdel över **centrala grammatiska begrepp**, följd av en **tematisk svensk–spansk fackordlista**.

---

## 1. Grammatiska begrepp A–Ö

### Ackusativobjekt (Direkt objekt)
*Spanska: complemento directo / objeto directo*  
Ackusativobjektet är den person eller sak som direkt påverkas av verbhandlingen. Det besvarar frågan *Vad?* eller *Vem?* subjektet ser, köper, analyserar etc.
- *Redacté **un correo formal**.* (Jag författade ett formellt mejl. – Vad författade jag?)
- *Saludamos **a la ponente**.* (Vi hälsade på föreläsaren. – Vem hälsade vi på?)
- Se även [Personliga pronomen](/docs/pronomen/personliga) och [Personligt a](/docs/prepositioner/personligt-a).

### Adjektiv
*Spanska: adjetivo*  
Ord som anger egenskaper, tillstånd eller karaktär hos ett substantiv eller pronomen. I spanskan rättar sig adjektivet efter substantivets genus och numerus (kongruens).
- *un informe **exhaustivo*** (en uttömmande rapport), *unas soluciones **prácticas*** (praktiska lösningar).
- Se även [Adjektivens kongruens](/docs/adjektiv/kongruens).

### Adverb
*Spanska: adverbio*  
Oböjliga ord som preciserar eller modifierar ett verb, ett adjektiv eller ett annat adverb. De besvarar frågor som *Hur?*, *När?*, *Var?* eller *I vilken grad?*.
- *Expuso sus ideas **brillantemente**.* (Hon lade fram sina idéer strålande.)
- *El tren llegó **anoche**.* (Tåget anlände igår kväll.)
- Se även [Adverben och deras användning](/docs/adverb/anvandning).

### Agent
*Spanska: complemento agente*  
Den person, grupp eller kraft som utför handlingen i en passiv konstruktion. I spanskan markeras agenten konsekvent med prepositionen **por**.
- *La sinfonía fue interpretada **por la filarmónica**.* (Symfonin framfördes av filharmonikerna.)
- Se även [Por och para](/mer/por-och-para).

### Apokopering
*Spanska: apócope*  
Ett fonetiskt och morfologiskt fenomen där ett ord förlorar en slutvokal eller slutstavelse framför vissa ord.
- *bueno* ➡️ ***buen** resultado*, *grande* ➡️ ***gran** científica*, *ciento* ➡️ ***cien** personas*.
- Se även [Apokopering](/mer/apokopering).

### Bestämd artikel
*Spanska: artículo determinado / definido*  
Formord som placeras framför substantivet för att signalera att referenten är specifik eller känd för lyssnaren: **el**, **la**, **los**, **las** (motsvarar svenskans slutartikel *-en, -et, -na*).
- ***el** archivo* (arkivet), ***la** propuesta* (förslaget), ***los** acuerdos* (överenskommelserna).
- Se även [Substantiv och artiklar](/docs/substantiv/artiklar).

### Dativobjekt (Indirekt objekt)
*Spanska: complemento indirecto / objeto indirecto*  
Den mottagare som handlingen riktar sig till, eller för vars räkning något sker (*åt, till eller för* vem).
- *Entregué el borrador **al editor**.* (Jag överlämnade utkastet till redaktören.)
- *¿**Nos** reservas dos localidades?* (Bokar du två platser åt oss?)
- Se även [Personliga pronomen](/docs/pronomen/personliga).

### Diminutiv och Augmentativ
*Spanska: sufijos apreciativos (diminutivos y aumentativos)*  
Ändelser som tillför nyanser av förminskning och affektion (*diminutiv*) eller förstoring och grovhet (*augmentativ*).
- Diminutiv: *café* ➡️ ***cafetito*** (en god kopp kaffe), *despacio* ➡️ ***despacito***.
- Augmentativ: *éxito* ➡️ ***exitazo*** (dundersuccé), *palabra* ➡️ ***palabrota*** (svordom, grovt ord).
- Se även [Ordbildning](/mer/ordbildning).

### Emfatisk omskrivning
*Spanska: perífrasis enfática de relativo*  
En satsklyvning som framhäver ett visst led i påståendet ("Det är/var ... som ...").
- *Fue el martes pasado cuando ratificaron el acuerdo.* (Det var i tisdags som de ratificerade avtalet.)
- *Es el equipo técnico el que diseñó la maqueta.* (Det är det tekniska teamet som ritade modellen.)
- Se även [Relativa pronomen](/docs/pronomen/relativa).

### Femininum och Maskulinum (Genus)
*Spanska: género gramatical (masculino y femenino)*  
De två grammatiska könen i det spanska nominalsystemet. Maskulina ord föregås av *el / un* och slutar ofta på *-o*; feminina ord föregås av *la / una* och slutar ofta på *-a*, *-ción*, *-dad*.
- Maskulinum: *el algoritmo*, *un puente*.
- Femininum: *la cumbre*, *una prioridad*.
- Se även [Substantivens genus](/docs/substantiv/genus).

### Förenad kontra självständig ställning
*Spanska: función adjetiva (determinante) vs función pronominal*  
- **Förenad ställning:** Pronomenet fungerar som ett bestämningsord direkt till ett substantiv (*nuestro proyecto*, *este dispositivo*).
- **Självständig ställning:** Pronomenet står ensamt och ersätter ett underförstått substantiv (*el nuestro*, *este*).
- Se även [Possessiva pronomen](/docs/pronomen/possessiva).

### Futurum
*Spanska: futuro simple y perifrástico*  
Tempus som förlägger handlingen till framtiden, antingen perifrastiskt (*ir a + infinitiv*: *vamos a negociar*) eller morfologiskt enkelt (*negociaremos*).
- Se även [Futurum](/docs/verb/tempus/futurum).

### Genitiv
*Spanska: genitivo / relación de posesión*  
Grammatisk relation som uttrycker tillhörighet eller ursprung. Där svenskan fäster ett foge-s (*forskarens slutsats*), fogar spanskan prepositionen **de** (*la conclusión del investigador*).
- Se även [Substantivens genitiv](/docs/substantiv/genitiv).

### Gerundium
*Spanska: gerundio*  
En oböjlig verbform med ändelserna **-ando** eller **-iendo** (*desarrollando, aprendiendo*). I förbindelse med *estar* uttrycker den att en process pågår i talögonblicket (*están debatiendo*).
- Se även [Gerundium](/docs/verb/tempus/gerundium).

### Grundtal och Ordningstal
*Spanska: numerales cardinales y ordinales*  
- **Grundtal:** kvantifierar ett absolut antal (*cuatro, quince, cien*).
- **Ordningstal:** anger ordningsföljd eller rangordning (*primero, segundo, tercer*).
- Se även [Grundtal](/docs/rakneord/grundtal) och [Ordningstal](/docs/rakneord/ordningstal).

### Imperativ
*Spanska: imperativo*  
Verbets modus för befallningar, uppmaningar och instruktioner.
- *¡Envía el archivo!* (Skicka filen!), *¡Consultad el horario!* (Konsultera tidtabellen!).
- Se även [Imperativ](/docs/verb/imperativ).

### Imperfekt
*Spanska: pretérito imperfecto*  
Ett förgånget tempus som målar upp bakgrundssituationer, vanemässiga förlopp och tillstånd utan skarp tidsbegränsning.
- *En aquella época la empresa **operaba** desde Valencia.* (På den tiden verkade företaget från Valencia.)
- Se även [Imperfekt](/docs/verb/tempus/imperfekt) och [Preteritum eller imperfekt?](/docs/verb/tempus/preteritum-eller-imperfekt).

### Indikativ
*Spanska: modo indicativo*  
Verbets verklighetsmodus för att skildra realiteter, fakta och säkra skeenden. Står i kontrast till konjunktiv.
- *Constatamos que la hipótesis es válida.* (Vi konstaterar att hypotesen är giltig.)

### Infinitiv
*Spanska: infinitivo*  
Verbets nominala grundform med ändelserna **-ar**, **-er** eller **-ir**.
- *analizar*, *comprender*, *distribuir*.
- Se även [Infinitiv](/docs/verb/infinitiv).

### Komparativ och Superlativ
*Spanska: grados de comparación (comparativo y superlativo)*  
Stegring av adjektiv och adverb:
- Positiv: *eficiente* (effektiv)
- Komparativ: *más eficiente* (effektivare)
- Relativ superlativ: *el más eficiente* (den mest effektiva)
- Absolut superlativ: *eficientísimo* (ytterst effektiv).
- Se även [Adjektivens komparation](/docs/adjektiv/komparation).

### Konjunktion
*Spanska: conjunción*  
Småord som sammankopplar satser eller satsdelar, antingen samordnande (*y, pero, o*) eller underordnande (*que, cuando, puesto que*).
- Se även [Sambandsord](/blog/sambandsord).

### Konjunktiv
*Spanska: modo subjuntivo*  
Verbets modus för subjektivitet, hypoteser, tvivel, viljeyttringar och framtida osäkerhet i bisatser.
- *Es indispensable que el equipo **colabore** activamente.* (Det är nödvändigt att teamet samarbetar aktivt.)
- Se även [Konjunktiv](/docs/verb/konjunktiv).

### Kongruens
*Spanska: concordancia*  
Grammatisk anpassning mellan satsdelar. Artiklar och adjektiv anpassar genus och numerus efter sitt huvudord, och predikatet anpassar person och numerus efter subjektet.

### Korrelat
*Spanska: antecedente*  
Det led i den överordnade satsen som ett relativt pronomen eller adverb pekar tillbaka på.
- *El informe* (korrelat) *que* (relativpronomen) *remitiste.*

### Modala hjälpverb
*Spanska: verbos modales / auxiliares de modalidad*  
Verb som förmedlar nödvändighet, tillåtelse, förmåga eller sannolikhet framför en infinitiv: *poder, deber, tener que, soler*.
- Se även [Modala hjälpverb](/docs/verb/modala-hjalpverb).

### Obestämd artikel
*Spanska: artículo indeterminado / indefinido*  
Artiklar som introducerar ospecificerade eller nya referenter i diskursen: **un**, **una**, **unos**, **unas**.
- *un esquema* (en skiss), *unas directrices* (några riktlinjer).

### Objektsformer (Personliga pronomen)
*Spanska: pronombres personales átonos de objeto*  
Trycksvaga pronomen som placeras framför det böjda verbet som direkt eller indirekt objekt (*me, te, lo, la, le, nos, os, los, las, les*).
- Se även [Personliga pronomen](/docs/pronomen/personliga).

### Opersonlig reflexiv form (Passivt se)
*Spanska: pasiva refleja y se impersonal*  
Strukturer med partikeln **se** för att uttrycka allmänna regler, passiva skeenden eller motsvarigheter till svenskans "man".
- *Se requieren dos copias compulsadas.* (Det krävs två bestyrkta kopior.)
- Se även [Opersonligt se](/mer/opersonligt-se).

### Particip (Perfekt particip)
*Spanska: participio pasivo*  
Adjektivisk verbform som slutar på **-ado** eller **-ido** (*aprobado, resuelto*). Tillsammans med *haber* skapar den sammansatta tempus (*han firmado*).
- Se även [Perfekt](/docs/verb/tempus/perfekt).

### Passiv sats
*Spanska: voz pasiva*  
Satskonstruktion där patienten (den som utsätts för handlingen) uppträder som grammatiskt subjekt (*El tratado fue firmado por los ministros*).

### Plural och Singular (Numerus)
*Spanska: número gramatical (singular y plural)*  
- **Singular:** avser en enhet (*un laboratorio*).
- **Plural:** avser två eller fler enheter (*varios laboratorios*).
- Se även [Substantivens plural](/docs/substantiv/plural).

### Predikat
*Spanska: predicado*  
Den satsdel som anger vad subjektet företar sig eller vilket tillstånd som råder. Består av eller leds av ett finitt verb.

### Prefix och Suffix
*Spanska: prefijos y sufijos derivativos*  
Morfologiska byggstenar för ordbildning:
- **Prefix:** ställs före stammen (*des-centralizar, re-organizar*).
- **Suffix:** fogas till stammens slut (*sostenib-ilidad, cre-ativo*).
- Se även [Ordbildning](/mer/ordbildning).

### Preposition
*Spanska: preposición*  
Oböjliga bindeord som relaterar substantivfraser till resten av satsen: *a, con, de, en, hacia, por, para, según, sin, sobre*.
- Se även [Prepositioner](/docs/prepositioner/introduktion).

### Prepositionsformer (Betonade personliga pronomen)
*Spanska: pronombres personales tónicos con preposición*  
Självständiga betonade pronominalformer som styrs av en preposition: *para mí, según tú, ante ellos, conmigo*.
- Se även [Personliga pronomen](/docs/pronomen/personliga).

### Presens
*Spanska: presente de indicativo*  
Tempus för samtida förhållanden, etablerade rutiner och tidlösa sanningar (*gestionamos, comprende, deciden*).
- Se även [Presens](/docs/verb/tempus/presens).

### Preteritum
*Spanska: pretérito perfecto simple / indefinido*  
Tempus för distinkta, avslutade handlingar i det förflutna med bestämda tidsramar.
- *El comité **aprobó** el presupuesto en su sesión extraordinaria.* (Utskottet godkände budgeten vid sitt extrasammanträde.)
- Se även [Preteritum](/docs/verb/tempus/preteritum).

### Pronomen
*Spanska: pronombre*  
Ordklass som ersätter eller refererar till en nominalfras: personliga, demonstrativa, possessiva, relativa, reflexiva, indefinita och interrogativa.

### Rektion
*Spanska: régimen verbal o preposicional*  
Ett visst verbs eller adjektivs obligatoriska krav på en specifik preposition.
- *insistir **en*** (hålla fast vid / insistera på), *depender **de*** (bero på), *aspirar **a*** (sträva efter).
- Se även [Verbkonstruktion och rektion](/docs/verb/verbkonstruktion).

### Subjekt
*Spanska: sujeto léxico o gramatical*  
Den aktör, entitet eller det fenomen som utför eller erfar handlingen, och som styr verbets person- och numerusändelse.

### Substantiv
*Spanska: sustantivo / nombre común o propio*  
Beteckningar på konkreta föremål, individer, geografiska platser och abstrakta begrepp (*innovación, Santiago, microchip*).

### Tempus
*Spanska: tiempo gramatical*  
Verbets tidsmässiga förankring i relation till talögonblicket: dåtid, nutid eller framtid.

### Verb
*Spanska: verbo*  
Kärnordklassen i satsen som förmedlar handling, tillstånd eller skeende.

## 2. Tematisk svensk–spansk fackordlista

För att underlätta fördjupad läsning presenteras termerna här ordnade efter funktionella grammatiska områden:

### A. Satsdelar och syntaktiska roller (*Sintaxis oracional*)

| Svensk term | Spansk fackterm | Kort funktionell förklaring |
| :--- | :--- | :--- |
| **subjekt** | sujeto | Den som utför eller styr verbhandlingen |
| **predikat** | predicado | Satsens verbala kärna |
| **ackusativobjekt (direkt objekt)** | complemento directo | Det som direkt utsätts för verbets verkan |
| **dativobjekt (indirekt objekt)** | complemento indirecto | Den till eller för vilken handlingen utförs |
| **agent** | complemento agente | Handlaren i en passiv verbkonstruktion (inleds med *por*) |
| **emfatisk omskrivning** | perífrasis enfática | Klyvning för att lyfta fram ett visst satsled |
| **ordföljd** | orden sintáctico / orden de palabras | Ledens inbördes sekvens i påstående eller fråga |

### B. Nominalsystem och ordbildning (*Morfología nominal y léxica*)

| Svensk term | Spansk fackterm | Kort funktionell förklaring |
| :--- | :--- | :--- |
| **substantiv** | sustantivo / nombre | Sakord och abstrakta benämningar |
| **bestämd artikel** | artículo definido / determinado | Markerar specifik referent (*el, la, los, las*) |
| **obestämd artikel** | artículo indefinido / indeterminado | Introducerar ny referent (*un, una, unos, unas*) |
| **adjektiv** | adjetivo calificativo | Beskriver substantivets egenskaper |
| **genitiv** | relación posesiva con *de* | Ägande och tillhörighet |
| **kongruens** | concordancia | Formmässig överensstämmelse i genus/numerus |
| **apokopering** | apócope | Trunkering av slutljud framför substantiv |
| **diminutiv** | diminutivo | Förminskande/affektiv suffixbildning |
| **augmentativ** | aumentativo | Förstorande/intensifierande suffixbildning |
| **prefix** | prefijo | Förled som fogas framför ordstammen |
| **suffix** | sufijo | Efterled som fogas till ordstammens slut |

### C. Verblära, tempus och modus (*Morfología verbal*)

| Svensk term | Spansk fackterm | Kort funktionell förklaring |
| :--- | :--- | :--- |
| **infinitiv** | infinitivo | Verbets nominala grundform (*-ar, -er, -ir*) |
| **gerundium** | gerundio | Pågående processform (*-ando, -iendo*) |
| **perfekt particip** | participio pasivo | Fullbordad form i sammansatta tempus (*-ado, -ido*) |
| **indikativ** | indicativo | Realitets- och faktamodus |
| **konjunktiv** | subjuntivo | Modus för hypoteser, vilja och ovisshet |
| **imperativ** | imperativo | Modus för direkta uppmaningar och direktiv |
| **presens** | presente | Samtida tempus |
| **preteritum** | pretérito indefinido | Avslutad historisk handling med punktkaraktär |
| **imperfekt** | pretérito imperfecto | Pågående, beskrivande eller vanemässig dåtid |
| **pluskvamperfekt** | pretérito pluscuamperfecto | Förfluten handling före en annan dåtidshandling |
| **futurum** | futuro | Framtida handling |
| **rektion** | régimen verbal | Verbets styrning av specifik preposition |
| **modala hjälpverb** | verbos auxiliares modales | Verb som modifierar modaliteten hos en infinitiv |

### D. Pronominalsystem och bindeord (*Pronombres y conectores*)

| Svensk term | Spansk fackterm | Kort funktionell förklaring |
| :--- | :--- | :--- |
| **personliga pronomen** | pronombres personales | Subjekts- och objektsmarkörer |
| **betonade prepositionsformer** | pronombres tónicos preposicionales | Självständiga pronomen efter preposition (*mí, ti...*) |
| **korrelat** | antecedente | Satsledet som ett relativt pronomen pekar tillbaka på |
| **konjunktion** | conjunción / nexo | Bindeord mellan satser och fraser |
| **preposition** | preposición | Bindeled som anger rum, tid eller abstrakt relation |
