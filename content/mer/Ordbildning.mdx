I spanskan genereras nya ord och lexikala uttryck i huvudsak genom två mekanismer:
1. **Sammansättning (*composición*):** Två självständiga lexikala led förenas till en ny funktionell enhet (exempelvis *abrelatas* eller *sala de conferencias*).
2. **Avledning (*derivación*):** En ordstam utökas med **prefix** (förstavelser) eller **suffix** (efterled), till exempel *nación* ➡️ *nacional* ➡️ *internacional*.

Därtill förfogar spanskan över ett synnerligen uttrycksfullt system av **affektiva suffix (diminutiv och augmentativ)** (*perrito*, *novelón*) som förmedlar nyanser av dimension, stil och känslomässig valör.

## 1. Sammansättningar (composición)

Till skillnad från germanska språk som svenskan, vilka ohämmat fuserar substantiv till sammansatta ord (*vinterdag*, *korkskruv*, *högtalare*), utnyttjar spanskan skilda syntaktiska mönster:

### A. Substantiv + preposition + substantiv / infinitiv
Detta är spanskans dominerande motsvarighet till svenska sammansättningar. Huvudparten av dessa förbindelser binds samman av **de**, men i specifika sammanhang nyttjas jämväl bindeord som **para**, **a**, **en** eller **sin**:

| Spansk konstruktion | Svenskt sammansatt begrepp |
| :--- | :--- |
| *una tarde **de** otoño* | en hösteftermiddag |
| *un equipo **de** buceo* | en dykutrustning |
| *un pastel **de** verduras* | en grönsakspaj |
| *moda **de** caballero* | herrmode |
| *el dolor **de** muelas* | tandvärken |
| *una máquina **de** soldar* | en svetsmaskin (med infinitiv) |
| *el cuarto **de** estudio* | arbetsrummet (med infinitiv) |
| *unos vasos **para** té helado* | några glas för iste |
| *la cocina **a** gas* | gasspisen |
| *la expedición **a** los fiordos* | fjordexpeditionen |
| *el aroma **a** café tostado* | kaffearomen |
| *el traslado **en** ferri* | färjeöverfarten |
| *la transmisión **en** directo* | direktsändningen |
| *un archivo **sin** registrar* | ett oregistrerat dokument |

### B. Substantiv + substantiv (i apposition)
Ett begränsat antal flerordiga benämningar utgörs av två substantiv ställda i direkt sekvens utan bindeord.

<Admonition type="important" title="Pluralbildning vid substantiv + substantiv">

I sammansatta nominalfraser av typen *substantiv + substantiv* böjs **uteslutande det första substantivet i plural**:
- *un caso límite* ➡️ *tres **casos** límite* (gränsfall)
- *un perro guía* ➡️ *dos **perros** guía* (ledarhundar)
- *la hora punta* ➡️ *las **horas** punta* (rusningstimmarna)
- *un hombre rana* ➡️ *dos **hombres** rana* (grodmän / yrkesdykare)
- *un niño prodigio* ➡️ *dos **niños** prodigio* (underbarn)
- *un coche bomba* ➡️ *dos **coches** bomba* (bilbomber)

</Admonition>

### C. Finit verbform + substantiv i plural
En ytterst produktiv spansk ordbildningstyp består av en **verbform i 3:e person singularis presens** sammanfogad med ett **substantiv i pluralis**:

| Sammansatt ord | Morfologiska beståndsdelar | Svensk motsvarighet |
| :--- | :--- | :--- |
| **el sacacorchos** | *saca* (drar ut) + *corchos* (korkar) | korkskruven |
| **el abrelatas** | *abre* (öppnar) + *latas* (konserver) | konservöppnaren |
| **el paraguas** | *para* (hejdar) + *aguas* (vattenflöden) | paraplyet |
| **el rascacielos** | *rasca* (skrapar) + *cielos* (skyar) | skyskrapan |
| **el cortacésped** | *corta* (klipper) + *césped* (gräsmatta) | gräsklipparen |
| **el lavavajillas** | *lava* (diskar) + *vajillas* (porslin) | diskmaskinen |
| **el parabrisas** | *para* (avvisar) + *brisas* (vindar) | vindrutan |
| **el matamoscas** | *mata* (dödar) + *moscas* (flugor) | flugsmällaren |
| **el pinchadiscos** | *pincha* (lägger på) + *discos* (skivor) | diskjockeyn |
| **el cumpleaños** | *cumple* (fullbordar) + *años* (år) | födelsedagen |

<Admonition type="tip" title="Genus och böjningsmönster">

Samtliga dessa sammansatta verb+substantiv-ord är **maskulina** (*el rascacielos*) och **invarianta i plural** (deras form ändras inte i pluralis): *un sacacorchos* ➡️ *dos **sacacorchos***.

</Admonition>

### D. Substantiv + klassificerande adjektiv
Många svenska sammansatta ord återges på spanska genom ett substantiv följt av ett preciserande adjektiv:
- *la energía solar* (solenergin)
- *el transporte público* (kollektivtrafiken)
- *la masa madre* (surdegen)
- *la banca digital* (nätbanken)
- *la reforma laboral* (arbetsmarknadsreformen)
- *una chaqueta de cuero sintético* (en skinnjacka i konstläder)
- *un vehículo de tracción total* (en fyrhjulsdriven bil)

### E. Sammansmältning med binde-i (substantiv + adjektiv)
En klassisk grupp bildningar sammanfogar ett kroppssubstantiv och ett adjektiv med bindevokalen **-i-**:
- *cabizbajo* (*cabeza* + *bajo* ➡️ med sänkt huvud, modfälld)
- *pelirrojo* (*pelo* + *rojo* ➡️ rödhårig)
- *paticorto* (*pata* + *corto* ➡️ kortbent)

### F. Lexikaliserade helfraser
- *el altavoz* (*alto* + *voz* ➡️ högtalaren)
- *el bienestar* (*bien* + *estar* ➡️ välbefinnandet)
- *la bocacalle* (*boca* + *calle* ➡️ tvärgatan)
- *la enhorabuena* (*en hora buena* ➡️ gratulationen)
- *el porqué* (*por qué* ➡️ orsaken, skälet)
- *un sabelotodo* (*sabe lo todo* ➡️ en allvetare / besserwisser)
- *bienvenido* (*bien* + *venido* ➡️ välkommen)

## 2. Suffix som bildar substantiv

Genom att addera efterled (*suffix*) till verbstammar, substantiv eller adjektiv skapas nya substantiviska ord:

### A. Från verbstam

| Suffix | Betydelse och funktion | Avledning | Svensk motsvarighet |
| :--- | :--- | :--- | :--- |
| **-ción / -sión / -ión** | Resultat, skeende eller process (feminina) | *digitalizar* ➡️ **la digitalización**<br />*invertir* ➡️ **la inversión**<br />*reunir* ➡️ **la reunión** | digitaliseringen<br />investeringen<br />mötet |
| **-miento / -mento** | Handling eller tillstånd (maskulina) | *agradecer* ➡️ **el agradecimiento**<br />*financiar* ➡️ **el financiamiento**<br />*reglamentar* ➡️ **el reglamento** | tacksamheten<br />finansieringen<br />regelverket |
| **-anza / -ancia / -encia** | Abstrakt tillstånd eller kvalitet | *confiar* ➡️ **la confianza**<br />*discrepar* ➡️ **la discrepancia**<br />*competir* ➡️ **la competencia** | förtroendet<br />meningsskiljaktigheten<br />kompetensen / konkurrensen |
| **-dor / -dora / -tor** | Aktör eller teknisk apparatur | *investigar* ➡️ **el investigador**<br />*coordinar* ➡️ **la coordinadora**<br />*imprimir* ➡️ **la impresora**<br />*enfriar* ➡️ **el enfriador**<br />*procesar* ➡️ **el procesador** | forskaren<br />samordnaren<br />skrivaren<br />kylaren<br />processorn |
| **-ante / -iente** | Utövare av viss handling | *participar* ➡️ **el/la participante**<br />*solicitar* ➡️ **el/la solicitante**<br />*asistir* ➡️ **el/la asistente** | deltagaren<br />den sökande<br />assistenten / åhöraren |

### B. Från substantivstam

| Suffix | Funktionell innebörd | Avledning | Svensk motsvarighet |
| :--- | :--- | :--- | :--- |
| **-ero / -era** | Yrkesutövare eller förvaringskärl | *enfermo* ➡️ **el enfermero**<br />*aduanas* ➡️ **el aduanero**<br />*billetera* ➡️ **la billetera**<br />*moneda* ➡️ **el monedero** | sjukskötaren<br />tulltjänstemannen<br />plånboken<br />portmonnän |
| **-ería** | Verksamhetslokal eller affärsrörelse | *relojero* ➡️ **la relojería**<br />*pastelería* ➡️ **la pastelería**<br />*joyería* ➡️ **la joyería** | uraffären<br />konditoriet<br />juvelerarbutiken |
| **-ado / -ada** | Omfång, samling eller plötslig stöt | *puño* ➡️ **un puñado**<br />*cuchara* ➡️ **una cucharada**<br />*frenazo* ➡️ **una frenada** | en handfull<br />en matsked<br />en kraftig inbromsning |
| **-azo** | Träff, slag eller intensiv signal | *timbre* ➡️ **un timbrazo**<br />*portazo* ➡️ **un portazo** | en ringsignal<br />en dörrsmäll |
| **-ista** | Specialitet, inriktning eller yrke | *diseño* ➡️ **el/la diseñador/diseñista**<br />*análisis* ➡️ **el/la analista** | formgivaren<br />analytikern |
| **-o (träd vs frukt)** | Maskulinum betecknar trädet, femininum frukten | *cereza* ➡️ **el cerezo**<br />*castaña* ➡️ **el castaño**<br />*manzana* ➡️ **el manzano** | körsbärsträdet<br />kastanjeträdet<br />äppelträdet |

### C. Från adjektivstam (abstrakta egenskaper)

| Suffix | Adjektivstam | Bildat abstraktum | Svensk betydelse |
| :--- | :--- | :--- | :--- |
| **-dad / -idad / -tad / -tud** | *solidario*<br />*rentable*<br />*generoso*<br />*leal*<br />*amplio* | **la solidaridad**<br />**la rentabilidad**<br />**la generosidad**<br />**la lealtad**<br />**la amplitud** | solidariteten<br />lönsamheten<br />generositeten<br />lojaliteten<br />vidden / bredden |
| **-ez / -eza** | *honrado*<br />*fluido*<br />*firme*<br />*noble*<br />*limpio* | **la honradez**<br />**la fluidez**<br />**la firmeza**<br />**la nobleza**<br />**la limpieza** | hederligheten<br />flytet<br />fastheten<br />ädelheten<br />renligheten |
| **-ía** | *valiente*<br />*audaz*<br />*eficaz* | **la valentía**<br />**la audacia**<br />**la eficacia** | modet<br />djärvheten<br />effektiviteten |
| **-ura** | *fresco*<br />*espeso* | **la frescura**<br />**la espesura** | friskheten<br />tätheten / snåren |

## 7. Diminutiv, augmentativ och pejorativa ändelser

Spanskan har ett helt spektrum av ändelser som modulerar grundordets omfång och känslomässiga intonation:

### A. Diminutivändelser (förminskande och affektiva)
- **-ito / -ita:** standardformen framför alla (*perrito, casita, momentito*).
- **-illo / -illa:** ofta mer vardagligt dämpande ton (*chiquillo, ventanilla*).
- **-ico / -ica:** karakteristisk för östra Spanien (Aragonien, Navarra, Murcia).
- **-uelo / -uela:** förminskande med ibland lätt melankolisk ton (*arroyuelo*).

#### Inskott av bindekonsonant (-cito)
1. **Ord som slutar på obetonat -o / -a tar direkt -ito / -ita:**  
   *plano* ➡️ **planito**, *carpeta* ➡️ **carpetita**.
2. **Ord på -e och konsonanterna -n, -r tar -cito / -cita:**  
   *puente* ➡️ **puentecito**, *motor* ➡️ **motorcito**, *avión* ➡️ **avioncito**.
3. **Korta enstaviga ord tar -ecito / -ecillo:**  
   *luz* ➡️ **lucecita**, *pez* ➡️ **pececito**, *red* ➡️ **redecilla**.

### B. Augmentativändelser (förstorande och förstärkande)
- **-ón / -ona:** markant storlek eller benägenhet:  
  *novela* ➡️ **el novelón** (stor och fängslande roman), *trabajar* ➡️ **trabajador / currante**.
- **-azo / -aza:** avsevärd volym eller kraftigt intryck:  
  *premio* ➡️ **un premiazo** (en storvinst), *éxito* ➡️ **un exitazo** (en jätteframgång).
- **-ote / -ota:** klumpig eller bastant storlek:  
  *libro* ➡️ **un librote** (en tjock lunta).

### C. Pejorativa ändelser (nedsättande nyans)
- **-ucho / -ucha:** *vivienda* ➡️ **casucha** (skjul), *cuarto* ➡️ **cuartucho** (skrubb).
- **-uza:** *gente* ➡️ **gentuza** (pack, slödder).
- **-ejo / -eja:** *palabra* ➡️ **palabreja** (krångligt/udda ord).

## 8. Lexikaliserade diminutiver och augmentativer

Många spanska ord som ursprungligen uppstod som diminutiver eller augmentativer har med tiden stelnat till helt självständiga fackord:

| Etablerat ord | Ursprunglig stam | Svensk betydelse |
| :--- | :--- | :--- |
| **el bocadillo** | *el bocado* (tuggan) | baguetten, smörgåsen |
| **el bolsillo** | *el bolso* (väskan) | fickan |
| **la bombilla** | *la bomba* (kulan/pumpen) | glödlampan |
| **la mesilla** | *la mesa* (bordet) | sängbordet |
| **la ventanilla** | *la ventana* (fönstret) | bilrutan / expeditionsluckan |
| **el mosquito** | *la mosca* (flugan) | myggan |
| **el pañuelo** | *el paño* (tygstycket) | näsduken |
| **el sillón** | *la silla* (stolen) | fåtöljen |
| **el cajón** | *la caja* (lådan) | utdragslådan |
| **el cinturón** | *la cintura* (midjan) | säkerhetsbältet / läderbältet |

### Kumulativa suffixkedjor
Det går utmärkt att foga flera ändelser efter varandra för ackumulerad uttryckskraft:
- *chico* ➡️ *chiquito* ➡️ **chiquitito** (pytteliten)
- *poco* ➡️ *poquito* ➡️ **poquitín** (en mikroskopisk gnutta)
- *calle* ➡️ *calleja* ➡️ **callejuela** (trång och vindlande gränd)
