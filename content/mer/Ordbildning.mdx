I spanskan skapas nya ord huvudsakligen på två sätt:
1. **Sammansättning (*composición*):** Två ord kombineras till en ny helhet (till exempel *abrelatas* eller *sala de estar*).
2. **Avledning (*derivación*):** Ett basord förses med **prefix** (förstavelser) eller **suffix** (ändelser), till exempel *nación* ➡️ *nacional* ➡️ *internacional*.

Dessutom har spanskan ett rikt och levande system av **diminutiv- och augmentativändelser** (*perrito*, *hombrazo*) som nyanserar storlek, känslor och stil.

---

## 1. Sammansättningar (composición)

Till skillnad från svenskan, som gärna fogar ihop ord till ett enda långt ord (*vinterdag*, *köksbord*, *gräsklippare*), använder spanskan flera olika konstruktioner:

### A. Substantiv + preposition + substantiv / infinitiv
Detta är spanskans vanligaste motsvarighet till svenska sammansatta substantiv. Den vanligaste prepositionen är **de**, men även **para**, **a**, **en** och **sin** används:

| Spansk konstruktion | Svenskt sammansatt ord |
| :--- | :--- |
| *un día **de** invierno* | en vinterdag |
| *un traje **de** baño* | en baddräkt |
| *un gratín **de** patatas* | en potatisgratäng |
| *ropa **de** señoras* | damkläder |
| *el dolor **de** cabeza* | huvudvärken |
| *una máquina **de** coser* | en symaskin (med infinitiv) |
| *la sala **de** estar* | vardagsrummet (med infinitiv) |
| *unas tazas **para** café* | några kaffekoppar |
| *el mando **a** distancia* | fjärrkontrollen |
| *el viaje **a** México* | Mexikoresan |
| *el olor **a** tabaco* | tobakslukten |
| *un viaje **en** barco* | en båtresa |
| *la televisión **en** color* | färgteven |
| *una cama **sin** hacer* | en obäddad säng |

### B. Substantiv + substantiv (utan preposition)
Ett mindre antal sammansättningar består av två substantiv direkt efter varandra.

<Admonition type="important" title="Pluralbildning">

I sammansättningar av typen *substantiv + substantiv* sätts pluraländelsen **bara på det första substantivet**:
- *un caso límite* ➡️ *tres **casos** límite* (gränsfall)
- *un perro guía* ➡️ *dos **perros** guía* (ledarhundar)
- *la hora punta* ➡️ *las **horas** punta* (rusningstiderna)
- *un hombre rana* ➡️ *dos **hombres** rana* (grodmän / dykare)
- *un niño prodigio* ➡️ *dos **niños** prodigio* (underbarn)
- *un coche bomba* ➡️ *dos **coches** bomba* (bilbomber)

</Admonition>

### C. Verb + substantiv i plural
En mycket produktiv spansk ordtyp bildas av en **verbform i 3:e person singular presens** + ett **substantiv i plural**:

| Sammansatt ord | Grunddelar | Svenska |
| :--- | :--- | :--- |
| **el sacacorchos** | *saca* (drar ur) + *corchos* (korkar) | korkskruven |
| **el abrelatas** | *abre* (öppnar) + *latas* (burkar) | konservöppnaren |
| **el paraguas** | *para* (stoppar) + *aguas* (vatten) | paraplyet |
| **el rascacielos** | *rasca* (skrapar) + *cielos* (himlar) | skyskrapan |
| **el cortacésped** | *corta* (klipper) + *césped* (gräs) | gräsklipparen |
| **el lavavajillas** | *lava* (diskar) + *vajillas* (serviser) | diskmaskinen |
| **el parabrisas** | *para* (stoppar) + *brisas* (vindar) | vindrutan |
| **el matamoscas** | *mata* (dödar) + *moscas* (flugor) | flugsmällaren |
| **el pinchadiscos** | *pincha* (sätter nål på) + *discos* (skivor) | diskjockeyn |
| **el cumpleaños** | *cumple* (fyller) + *años* (år) | födelsedagen |

<Admonition type="tip" title="Genus och plural">

Alla dessa ord är **maskulina** (*el sacacorchos*) och är **invarianta i plural** (de ändrar inte form): *un sacacorchos* ➡️ *dos **sacacorchos***.

</Admonition>

### D. Substantiv + adjektiv (två ord)
Substantiv och adjektiv motsvaras på svenska ofta av ett sammansatt ord:
- *la mortalidad infantil* (barnadödligheten)
- *la industria textil* (textilindustrin)
- *el pan integral* (fullkornsbrödet)
- *el cajero automático* (bankomaten)
- *la reforma agraria* (jordreformen)
- *un vestido de manga larga* (en långärmad klänning)
- *un hombre de baja estatura* (en kortvuxen man)

### E. Substantiv + adjektiv (ett hopskrivet ord med -i-)
En liten grupp ord fogar ihop ett substantiv och ett adjektiv med bindevokalen **-i-**:
- *boquiabierto* (*boca* + *abierto* ➡️ med öppen mun, häpen)
- *pelirrojo / pelirrubio* (*pelo* + *rojo/rubio* ➡️ rödhårig / ljushårig)

### F. Andra sammansättningar
- *el altavoz* (*alto* + *voz* ➡️ högtalaren)
- *el bienestar* (*bien* + *estar* ➡️ välståndet / välbefinnandet)
- *la bocacalle* (*boca* + *calle* ➡️ tvärgatan / sidogatan)
- *la enhorabuena* (*en hora buena* ➡️ gratulationen)
- *el porqué* (*por qué* ➡️ anledningen, skälet)
- *un sabelotodo* (*sabe lo todo* ➡️ en besserwisser)
- *bienvenido* (*bien* + *venido* ➡️ välkommen)

## 2. Suffix som bildar substantiv

Genom att lägga till ändelser (*suffix*) på verb, substantiv eller adjektiv bildas nya substantiv:

### A. Från verbstam

| Suffix | Betydelse och funktion | Exempel | Svenska |
| :--- | :--- | :--- | :--- |
| **-ción / -sión / -ión** | Handling, resultat eller process (feminina ord) | *circular* ➡️ **la circulación**<br />*decidir* ➡️ **la decisión**<br />*reunir* ➡️ **la reunión** | trafiken, cirkulationen<br />beslutet<br />mötet |
| **-miento / -mento** | Handling eller mentalt tillstånd (maskulina ord) | *pensar* ➡️ **el pensamiento**<br />*sentir* ➡️ **el sentimiento**<br />*jurar* ➡️ **el juramento** | tanken<br />känslan<br />eden |
| **-anza / -ancia / -encia** | Egenskap, tillstånd eller abstrakt begrepp | *esperar* ➡️ **la esperanza**<br />*abundar* ➡️ **la abundancia**<br />*existir* ➡️ **la existencia** | hoppet<br />överflödet<br />existensen |
| **-dor / -dora / -tor** | Person som utför handlingen eller apparat/verktyg | *pescar* ➡️ **el pescador**<br />*vender* ➡️ **el vendedor**<br />*aspirar* ➡️ **la aspiradora**<br />*despertar* ➡️ **el despertador**<br />*ordenar* ➡️ **el ordenador** | fiskaren<br />försäljaren<br />dammsugaren<br />väckarklockan<br />datorn |
| **-ante / -iente** | Person som utför en aktivitet | *estudiar* ➡️ **el/la estudiante**<br />*habitar* ➡️ **el habitante**<br />*oír* ➡️ **el/la oyente** | studenten<br />invånaren<br />åhöraren |

### B. Från substantivstam

| Suffix | Betydelse och funktion | Exempel | Svenska |
| :--- | :--- | :--- | :--- |
| **-ero / -era** | Yrke eller föremål förknippat med saken | *carta* ➡️ **el cartero**<br />*zapato* ➡️ **el zapatero**<br />*carta* ➡️ **la cartera**<br />*ceniza* ➡️ **el cenicero** | brevbäraren<br />skomakaren<br />portföljen, plånboken<br />askkoppen |
| **-ería** | Butik, verkstad eller lokal (bildas ofta på *-ero*) | *zapatero* ➡️ **la zapatería**<br />*panadero* ➡️ **la panadería**<br />*peluquero* ➡️ **la peluquería** | skobutiken<br />bageriet<br />frisersalongen |
| **-ado / -ada** | Innehåll, mängd eller handling | *puño* ➡️ **un puñado**<br />*cuchara* ➡️ **una cucharada**<br />*pata* ➡️ **una patada** | en handfull<br />en skedfull<br />en spark |
| **-azo** | Slag med ett föremål eller signal | *porra* ➡️ **un porrazo**<br />*teléfono* ➡️ **un telefonazo** | ett batongslag<br />en telefonsignal |
| **-ista** | Yrke, ideologi eller sysselsättning | *deporte* ➡️ **el/la deportista**<br />*periódico* ➡️ **el/la periodista** | idrottaren<br />journalisten |
| **-o (träd vs frukt)** | Maskulinum anger träd, femininum frukten | *cereza* (körsbär) ➡️ **el cerezo**<br />*naranja* (apelsin) ➡️ **el naranjo**<br />*oliva* (oliv) ➡️ **el olivo** | körsbärsträdet<br />apelsinträdet<br />olivträdet |

### C. Från adjektivstam (abstrakta substantiv)

| Suffix | Grundord | Bildat substantiv | Svenska |
| :--- | :--- | :--- | :--- |
| **-dad / -idad / -tad / -tud** | *bueno* (god)<br />*feliz* (lycklig)<br />*difícil* (svår)<br />*libre* (fri)<br />*joven* (ung) | **la bondad**<br />**la felicidad**<br />**la dificultad**<br />**la libertad**<br />**la juventud** | godheten<br />lyckan<br />svårigheten<br />friheten<br />ungdomen |
| **-ez / -eza** | *viejo* (gammal)<br />*tímido* (blyg)<br />*bello* (vacker)<br />*pobre* (fattig)<br />*triste* (sorgsen) | **la vejez**<br />**la timidez**<br />**la belleza**<br />**la pobreza**<br />**la tristeza** | ålderdomen<br />blygheten<br />skönheten<br />fattigdomen<br />sorgsenheten |
| **-ía** | *alegre* (glad)<br />*cobarde* (feg)<br />*cortés* (artig) | **la alegría**<br />**la cobardía**<br />**la cortesía** | glädjen<br />fegheten<br />artigheten |
| **-ura** | *loco* (galen)<br />*tierno* (öm) | **la locura**<br />**la ternura** | galenskapen<br />ömheten |

## 7. Diminutiv, augmentativ och pejorativa ändelser

Spanskan har ett helt spektrum av ändelser som förändrar grundordets storlek, valör och känsloladdning:

### A. Diminutivändelser (förminskande och smekande)
- **-ito / -ita:** den absolut vanligaste ändelsen (*perrito*, *casita*, *momentito*).
- **-illo / -illa:** ofta lite mer neutral eller dämpad ton (*chiquillo*, *florecilla*).
- **-ico / -ica:** regional i östra Spanien (Aragón, Navarra, Murcia: *cafetico*).
- **-uelo / -uela:** ibland något nedsättande (*arroyuelo*, *mujerzuela*).

#### Växlingen mellan -ito och -cito
När används *-ito* och när skjuts ett *-c-* in (*-cito*)?
1. **Ord på -o och -a ➡️ -ito / -ita:**  
   *gato* ➡️ **gatito**, *casa* ➡️ **casita**, *abuela* ➡️ **abuelita**.
2. **Ord på -e och konsonanterna -n, -r ➡️ -cito / -cita:**  
   *madre* ➡️ **madrecita**, *calor* ➡️ **calorcito**, *salón* ➡️ **saloncito**.
3. **Enstaviga ord ➡️ -ecito / -ecillo:**  
   *pan* ➡️ **panecillo**, *flor* ➡️ **florecita**, *sol* ➡️ **solecito**.

### B. Augmentativändelser (förstorande och förstärkande)
- **-ón / -ona:** storlek eller intensiv egenskap:  
  *silla* ➡️ **el sillón** (fåtölj), *dormir* ➡️ **dormilón** (sjusovare), *simpático* ➡️ **simpaticón**.
- **-azo / -aza:** storlek eller kraftfull handling/slag:  
  *perro* ➡️ **perrazo** (stor vovve), *hombre* ➡️ **hombrazo** (stor, kraftig man).
- **-ote / -ota:** klumpig eller överdrivet stor:  
  *amigo* ➡️ **amigote** (polare), *grande* ➡️ **grandote** (jättestor).

### C. Pejorativa ändelser (nedsättande)
- **-ucho / -ucha:** *casa* ➡️ **casucha** (ruckel), *cuarto* ➡️ **cuartucho** (skrubb), *animal* ➡️ **animalucho**.
- **-uza:** *gente* ➡️ **gentuza** (pack, slödder).
- **-ejo / -eja:** *animal* ➡️ **animalejo** (skadedjur), *calle* ➡️ **calleja** (gränd).

## 8. Avledda substantiv med självständig betydelse

Flera ord som ursprungligen var diminutiver eller augmentativer har blivit helt självständiga substantiv:

| Avlett substantiv | Grundord | Svensk betydelse |
| :--- | :--- | :--- |
| **el bocadillo** | *el bocado* (munsbiten) | smörgåsen, baguetten |
| **el bolsillo** | *el bolso* (väskan) | fickan |
| **la cerilla** | *la cera* (vaxet) | tändstickan |
| **la mesilla** | *la mesa* (bordet) | sängbordet / nattduksbordet |
| **la ventanilla** | *la ventana* (fönstret) | biljettluckan / bilrutan |
| **el mosquito** | *la mosca* (flugan) | myggan |
| **el pañuelo** | *el paño* (duken) | näsduken |
| **el sillón** | *la silla* (stolen) | fåtöljen |
| **el cajón** | *la caja* (lådan/asken) | byrålådan |
| **el cinturón** | *la cintura* (midjan) | skärpet / bilbältet |

### Flera ändelser på samma ord
Det går utmärkt att bygga på flera ändelser för extra uttryckskraft:
- *chico* ➡️ *chiquito* ➡️ **chiquitito** (pytteliten)
- *poco* ➡️ *poquito* ➡️ **poquitín** (en liten gnutta)
- *calle* ➡️ *calleja* ➡️ **callejuela** (liten trång gränd)
